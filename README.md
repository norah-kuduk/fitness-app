# Physical Therapy App
This project is a modern, cross-platform physical therapy application built with Flutter and Dart. It supports athletes and individuals managing chronic injuries by offering personalized exercise plans and tracking tools. 

The project was started in Summer 2024 as a St. Lawrence University Fellowship. The project was then continued as an Senior Year Experience (SYE) Honors Project in the Fall of 2024 as part of my Computer Science major. 

## Project Summary
The app features scheduling and calendar views for therapy routines, combining a standard library of exercises with options for full user customization. It delivers a seamless experience across platforms through responsive design.

AI tools like ChatGPT and GitHub Copilot were integrated throughout development to streamline coding, debugging, and problem-solving. The backend uses PostgreSQL hosted in a Docker container, supported by RESTful endpoints for data management and retrieval. A relational data model stores exercises, routines, repetitions, and user customization data to ensure efficient handling of progress information.

This project demonstrates the intersection of health technology, AI-assisted development, and cross-platform mobile design.
